Trames en mémoire

Cliquez sur une ligne pour la sélectionner (elle passe en bleu) : les commandes du ruban agissent alors sur cette trame. Double-clic sur une ligne : générer un document. Mise à jour possible uniquement si la nouvelle version reste rétro-compatible (au minimum les mêmes balises).

Modèles

Un modèle est une trame dont tout ou partie des balises sont remplacées par une valeur fixe. Sélectionnez une ligne puis utilisez le ruban (double-clic : générer un document depuis ce modèle).

Documents générés

Chaque document généré a un code unique et un nom de la forme prefixe-code-titre.ext. Sélectionnez une ligne puis utilisez le ruban.
